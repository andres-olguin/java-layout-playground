# Java Layout Playground

Laboratorio educativo de Java Swing. Conserva el ejercicio original `Border.java` y añade una galería comparativa de `BorderLayout`, `GridLayout` y `FlowLayout`.

## Requisitos y ejecución

Requiere JDK 21+ y escritorio con interfaz gráfica.

```bash
javac Border.java examples/LayoutGallery.java
java Border
java -cp examples LayoutGallery
```

## Estado y límites

Ejemplos didácticos, no un editor visual ni herramienta comercial. La CI compila, pero **no certifica la experiencia visual**. Probar manualmente redimensionamiento y navegación por teclado antes de publicar capturas.

Próximos hitos: `CardLayout`, `BoxLayout`, ejemplos de accesibilidad, pruebas manuales y documentación visual. Se preserva el archivo de clase original y el estudio de evolución del 30/10/2026.
